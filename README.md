# 🎮 Rock Paper Scissors

A simple command-line Rock Paper Scissors game built with Python. The player chooses Rock, Paper, or Scissors, and the computer randomly selects its choice.

## 🎯 Features

- 🪨 Rock, Paper, Scissors gameplay
- 🎲 Random computer choice
- 👤 User input handling
- 🏆 Automatic winner determination
- 🤝 Draw detection
- ❌ Invalid input handling
- 🧱 Implemented using a Python class

## 🛠️ Technologies Used

- Python
- Random module
- Object-Oriented Programming (OOP)

## ▶️ How to Run

Clone the repository:

```bash
git clone https://github.com/jSrishti8002/rock-paper-scissors-python.git
```

## Open the project folder:
```bash
cd rock-paper-scissors-python
```

## Run the program:
```bash
python main.py
```

## 🎮 Example

enter rock/paper/scissors: rock
You chose rock
computer chose scissors

Result: You Win 🎉

## 🧠 Game Rules

Player Choice   |  	   Beats
🪨 Rock	        |    ✂️ Scissors
📄 Paper	      |     🪨 Rock
✂️ Scissors     |   	📄 Paper


If both the player and computer choose the same option, the result is a draw.
